**GDrive Mount** подключает ваше облачное хранилище Google Drive (включая тарифы Google One до 5 ТБ и более) в виде виртуального диска в Проводнике Windows (например, диск `G:` или `H:`). 

Приложение работает в фоновом режиме через системный трей, поддерживает автозапуск при входе в систему и обеспечивает быстрое кэширование файлов для комфортной работы.

---

## ✨ Возможности

- 💿 **Виртуальный диск Windows** — Google Drive отображается как полноценный физический накопитель в Проводнике.
- 🔐 **Безопасная авторизация** — вход в Google через браузер по официальному протоколу OAuth 2.0 в один клик.
- 🚀 **Автозапуск с Windows** — автоматическое подключение диска при старте системы без всплывающих окон консоли.
- 🔽 **Управление из трея** — аккуратная иконка в панели задач со статусом подключения и контекстным меню.
- 📁 **Прозрачная работа с файлами** — чтение, запись, копирование, переименование и удаление прямо из любых программ Windows.
- ⚡ **Умное VFS-кеширование** — локальный кэш для быстрой работы с часто открываемыми файлами.
- 🔄 **Автоматическое переподключение** — восстановление связи при разрыве интернет-соединения или выходе из спящего режима.
- 👥 **Быстрое переключение аккаунтов** — смена Google-аккаунта прямо из меню программы.

## 📋 Системные требования

| Компонент | Требование | Примечание |
|-----------|------------|------------|
| **ОС** | Windows 10 / 11 (64-bit) | Поддерживаются любые редакции |
| **Драйвер** | [WinFsp](https://winfsp.dev/rel/) | **Обязателен** (драйвер виртуальных файловых систем) |
| **Python** | 3.10+ | Требуется только при запуске из исходников |
| **Аккаунт** | Google / Google One | Бесплатный или любой платный тариф (от 15 ГБ до 5 ТБ+) |

> ℹ️ *Примечание:* Если WinFsp ещё не установлен, мастер первоначальной настройки программы сам определит это и предложит скачать его в один клик.

## 🚀 Быстрый старт

### Вариант 1: Запуск готового `.exe` (для пользователей)

1. Установите [WinFsp](https://winfsp.dev/rel/).
2. Скачайте свежий `GDriveMount.exe` из раздела [Releases](https://github.com).
3. Запустите файл и следуйте подсказкам мастера настройки.

---

### Вариант 2: Запуск из исходного кода (для разработчиков)

1. Клонируйте репозиторий:
   ```powershell
   git clone https://github.com/your-username/gdrive-mount.git
   cd gdrive-mount
   ```

2. Запустите автоматическую установку окружения и зависимостей:
   ```powershell
   .\install.bat
   ```

3. Запустите программу:
   ```powershell
   .\venv\Scripts\python.exe gdrive_mount_app.py
   ```

---

### Вариант 3: Сборка собственного `.exe`

В проект уже включен скрипт компиляции через **PyInstaller**:

```powershell
# 1. Установите зависимости (если ещё не сделано)
.\install.bat

# 2. Запустите сборку
.\build.bat
```
После завершения готовый исполняемый файл появится по пути: `dist\GDriveMount.exe`.

## 🧭 Первый запуск и мастер настройки

При первом открытии программы запустится пошаговый мастер:
1. **Проверка драйвера WinFsp** — диагностика наличия драйвера в системе.
2. **Загрузка rclone** — автоматическое скачивание актуального движка rclone (≈15 МБ).
3. **Выбор буквы диска** — выбор свободной буквы (по умолчанию `G:`).
4. **Авторизация в Google** — откроется страница в браузере для безопасного подтверждения доступа.

После завершения настройки программа сворачивается в системный трей и монтирует диск.

## 💡 Использование

### Меню в системном трее

Кликните правой кнопкой мыши по иконке приложения в области уведомлений Windows:

| Пункт меню | Описание |
|------------|----------|
| 🔗 **Подключить / 🔌 Отключить** | Ручное управление монтированием диска |
| 📂 **Открыть в проводнике** | Быстрый переход к букве диска в Windows Explorer |
| 🚀 **Автозапуск с Windows** | Включение / отключение запуска при загрузке системы |
| ℹ️ **Информация о диске** | Просмотр занятого и свободного места на Google Диске |
| 🌐 **Google Drive в браузере** | Открыть веб-версию Google Drive |
| 🔄 **Сменить аккаунт Google** | Сброс текущей сессии и авторизация под новым аккаунтом |
| ❌ **Выход** | Безопасное размонтирование диска и закрытие программы |

### Аргументы командной строки

```powershell
# Обычный запуск программы
python gdrive_mount_app.py

# Тихий запуск (для работы из планировщика задач или автозапуска)
python gdrive_mount_app.py --silent

# Принудительное указание буквы диска (например, X)
python gdrive_mount_app.py --drive-letter X

# Сброс текущих настроек и повторный вызов мастера
python gdrive_mount_app.py --reset

# Запуск приложения в трее без автоматического монтирования
python gdrive_mount_app.py --no-mount
```

## 🔧 Где хранятся настройки и кэш?

Все пользовательские данные хранятся изолированно в каталоге пользователя:
`%LOCALAPPDATA%\GDriveMount\` (`C:\Users\<Имя>\AppData\Local\GDriveMount\`)

- `config.json` — конфигурация буквы диска, флага автозапуска и путей.
- `rclone.conf` — параметры подключения rclone и OAuth-токены Google.
- `rclone/rclone.exe` — бинарный файл движка.
- `vfs-cache/` — кэшированные файлы для быстрого офлайн/онлайн чтения.
- `logs/` — диагностические журналы работы (`app.log`, `rclone.log`).

## ❓ FAQ и решение проблем

<details>
<summary><b>Диск не появляется в Проводнике после запуска</b></summary>

1. Убедитесь, что установлен драйвер **WinFsp** (скачать: [winfsp.dev](https://winfsp.dev/rel/)). Без него Windows не может смонтировать виртуальную FUSE-систему.
2. Проверьте, не занята ли выбранная буква диска (например, `G:`) флешкой или другим сетевым диском. Попробуйте другую букву через `python gdrive_mount_app.py --drive-letter H`.
3. Ознакомьтесь с логами ошибок: `%LOCALAPPDATA%\GDriveMount\logs\rclone.log`.
</details>

<details>
<summary><b>Безопасно ли использовать этот клиент?</b></summary>

Да. Авторизация происходит через стандартный протокол Google OAuth 2.0 в вашем браузере. Токены доступа сохраняются исключительно локально на вашем компьютере в `%LOCALAPPDATA%\GDriveMount\rclone.conf`. Никакие данные третьим лицам не передаются.
</details>

<details>
<summary><b>Как полностью удалить программу и её данные?</b></summary>

1. Закройте программу через пункт «Выход» в трее.
2. Удалите каталог с настройками: `%LOCALAPPDATA%\GDriveMount\`.
3. Если была включена автозагрузка, программа автоматически очищает ключ реестра при выключении автозапуска в меню.
</details>
